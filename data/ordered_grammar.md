# Hungarian Grammar

## Pronouns

### Demonstrative Pronouns

#### Core Rule
If a noun takes a case suffix or a postposition, the demonstrative pronoun `ez / az` must take the same case or postposition. This is called demonstrative agreement.

#### Examples
- `ez a könyv` → `ezt a könyvet` (`this book` → `this book` (ACC))
- `ez a ház` → `ebben a házban` (`this house` → `in this house`)
- `ez a fa` → `ez alatt a fa alatt` (`this tree` → `under this tree`)
- `ez előtt a ház előtt` = in front of this house
- `ez mögött a fal mögött` = behind this wall
- `ez mellett az autó mellett` = next to this car
- `ez alatt a fa alatt` = under this tree

#### Important
- `ez a házban` is wrong. Correct: `ebben a házban`
- `ez a könyvet` is wrong. Correct: `ezt a könyvet`
- `ez a fa alatt` is wrong. Correct: `ez alatt a fa alatt`

#### Quick rule
When using `ez / az`, copy the noun's case suffix or postposition onto the demonstrative.

### Personal Pronouns

- `engem` - me
- `téged` - you
- `őt` - her/him
- `önt` - you (formal)
- `minket` - us
- `titeket` - you (pl)
- `őket` - them
- `önöket` - you (pl) (formal)
- `magamat` - myself
- `magadat` - yourself

## Sentence Patterns & Useful Expressions

### `is`

`is` = also / too / as well

- `Én is.` = Me too.
- `Te is.` = You too.
- `Mi is.` = We too.
- `Ez is.` = This too.

#### Rule
`is` comes immediately after the word it modifies.

### Asking someone's name

- `Mi a neved?` = What's your name? (`What is your name?`)
- `Hogy hívnak?` = What's your name? (`What do people call you?`)
- `Hogy hívjalak?` = What should I call you? / How should I address you?
- `A nevem Mateusz.` = My name is Mateusz.
- `Mateusznak hívnak.` = They call me Mateusz. (`My name is Mateusz.`)

#### Pattern
- `hívnak` → they call (you)
- `hívjalak` → I should call you (`I → you`)

### `majd`

`majd` = later / then / someday / only / not until

- `Majd jövök.` = I will come later.
- `Majd holnap.` = Tomorrow.
- `Majd később.` = Later.
- `Majd meglátjuk.` = We will see.

### Liking

- `szeret` → to like / love (`lubić`, `kochać`) → `Szeretem a pizzát.` = I like pizza.
- `kedvel` → to be fond of (`darzyć sympatią`) → `Kedvelem Pétert.` = I like / am fond of Péter.
- `tetszik` → "is pleasing to" (`podoba się komuś`) → thing + `tetszik` + `nekem/neked...` → `Tetszik nekem ez az autó.` = I like this car.
- `ízlik` → "tastes good to" (`smakuje komuś`) → thing + `ízlik` + `nekem/neked...` → `Ízlik nekem a pizza.` = Pizza tastes good to me.
- `örül` → to be glad / be happy about (`cieszyć się z czegoś`) → `örül valaminek` (`-nak/-nek`) → `Örülök az ajándéknak.` = I am happy about the present.

## Nouns

### Plural

#### Core rule
Plural is formed with `-k`, and the connecting vowel follows vowel harmony.

#### Examples
- `kutya` → `kutyák`
- `könyv` → `könyvek`
- `autó` → `autók`

#### After numbers
Use the singular noun after numbers.

- `egy kutya`
- `két kutya`
- `öt kutya`
- `huszonnyolc kutya`
- `száz könyv`

Incorrect:
- `két kutyák`

#### After quantity words
Usually use singular after quantity words.

- `sok kutya`
- `sok ember`
- `kevés pénz`
- `néhány könyv`
- `rengeteg autó`

#### Generic statements
Hungarian often uses the singular form for things in general where English uses the plural.

- `A kutya hűséges.` = Dogs are faithful.
- `A tigris veszélyes.` = Tigers are dangerous.
- `A macska szeret aludni.` = Cats like sleeping.

The singular represents the whole species or class.

#### Specific group
Use the plural when referring to specific, identifiable items.

- `A kutyák a kertben vannak.` = The dogs are in the garden.
- `A tigrisek az állatkertben vannak.` = The tigers are in the zoo.

#### Possessed nouns
Numbers do not change the rule.

- `két barátom`
- `három testvérem`

Incorrect:
- `két barátaim`

#### Predicate agreement
Plural subject → plural adjective / predicate.

- `A kutyák nagyok.` = The dogs are big.
- `Az autók gyorsak.` = The cars are fast.
- `Két kutya van.` = There are two dogs.

#### Core intuition
Hungarian usually avoids marking plurality twice. If plurality is already clear from a number, a quantity word, or a generic meaning, the noun usually remains singular. Plural `-k` is mainly used when the noun itself must indicate "more than one".

#### Quick summary
Use singular:
- after numbers
- after quantity words
- when talking about a species or class in general

Use plural:
- when referring to a specific group
- when nothing else already indicates plurality

#### Common mistakes
- `két kutyák` → `két kutya`
- `sok könyvek` → `sok könyv`
- `három barátaim` → `három barátom`
- `A tigrisek veszélyes.` when talking about the species → `A tigris veszélyes.`

### Possession

#### Singular noun possession

- 1st person singular (`én`): `-m/-om/-em/-öm` (`barátom`, `házam`)
- 2nd person singular (`te`): `-d/-od/-ed/-öd` (`barátod`, `házad`)
- 3rd person singular (`ő`): `-ja/-je/-a/-e` (`barátja`, `háza`)
- 1st person plural (`mi`): `-nk/-unk/-ünk` (`barátunk`, `házunk`)
- 2nd person plural (`ti`): `-tok/-tek/-tök` (`barátotok`, `házatok`)
- 3rd person plural (`ők`): `-juk/-jük/-uk/-ük` (`barátjuk`, `házuk`)

#### Note on nouns ending in a vowel
- If the noun ends in a vowel, 3rd-person suffix uses `-ja / -je`. Examples: `anya → anyja`, `fiú → fiúja`
- If the noun ends in a consonant, use `-a / -e`. Examples: `ház → háza`, `barát → barátja`

#### Possessive plural
ONE → MANY = add `-i-` before the possessive ending.

- `én: -m → -im` (`barátom` → `barátaim`)
- `te: -d → -id` (`barátod` → `barátaid`)
- `ő: -ja/-je/-a/-e → -i` (`barátja` → `barátai`)
- `mi: -nk → -ink` (`barátunk` → `barátaink`)
- `ti: -tok/-tek/-tök → -itok/-itek` (`barátotok` → `barátaitok`)
- `ők: -juk/-jük/-uk/-ük → -ik` (`barátjuk` → `barátaik`)

Example:
- `videód` → `videóid` = your video → your videos

#### Note on plural + possessive combination
When the noun is plural and you add a possessive ending, the plural vowel changes. The forms come from `word + -k` (plural) + possessive ending.

Example breakdown:
- `barát` → `barátok` → `barátaim`

#### Irregular stem changes in possessives
Some common nouns change their vowel in possessive forms:

- `név` → `nevem / neved / neve`
- `kéz` → `kezem / kezed / keze`
- `tűz` → `tüze`
- `fül` → `fülem / füle`

### Cases

#### Core reference

1. Nominative: `—` (`ház`, `park`)
2. Accusative: `-t/-ot/-at/-et` (`házat`, `parkot`)
3. Dative: `-nak/-nek` (`Katinak`, `gyereknek`)
4. Inessive: `-ban/-ben` (`házban`, `parkban`)
5. Superessive: `-on/-en/-ön` (`asztalon`, `széken`, `földön`)

#### Additional full reference

1. Nominative
- Suffix: `—`
- Meaning: subject
- Question: `kto? co?`
- Example: `A kutya alszik.` = The dog is sleeping. / Pies śpi.

2. Accusative
- Suffix: `-t/-ot/-at/-et`
- Meaning: direct object
- Question: `kogo? co?`
- Example: `Látom a kutyát.` = I see the dog. / Widzę psa.

3. Dative
- Suffix: `-nak/-nek`
- Meaning: to / for
- Question: `komu? czemu?`
- Example: `Adok vizet a kutyának.` = I give water to the dog. / Daję psu wodę.

4. Inessive
- Suffix: `-ban/-ben`
- Meaning: in / inside / w
- Question: `gdzie?`
- Example: `A könyv a táskában van.` = The book is in the bag. / Książka jest w torbie.

5. Illative
- Suffix: `-ba/-be`
- Meaning: into / do środka
- Question: `dokąd?`
- Example: `Bemegyek a házba.` = I am going into the house. / Wchodzę do domu.

6. Elative
- Suffix: `-ból/-ből`
- Meaning: out of / ze środka
- Question: `skąd?`
- Example: `Kijövök a házból.` = I come out of the house. / Wychodzę z domu.

7. Superessive
- Suffix: `-on/-en/-ön`
- Meaning: on / na
- Question: `gdzie?`
- Example: `A telefon az asztalon van.` = The phone is on the table. / Telefon jest na stole.

8. Sublative
- Suffix: `-ra/-re`
- Meaning: onto / na (ruch)
- Question: `dokąd?`
- Example: `Felteszem az asztalra.` = I put it onto the table. / Kładę to na stół.

9. Delative
- Suffix: `-ról/-ről`
- Meaning: off / from a surface / z
- Question: `skąd?`
- Example: `Leveszem az asztalról.` = I take it off the table. / Zdejmuję to ze stołu.

10. Adessive
- Suffix: `-nál/-nél`
- Meaning: at / by / u, przy
- Question: `gdzie?`
- Example: `Péternél vagyok.` = I am at Péter's place. / Jestem u Pétera.

11. Allative
- Suffix: `-hoz/-hez/-höz`
- Meaning: to / towards / do
- Question: `dokąd?`
- Example: `Megyek az orvoshoz.` = I am going to the doctor. / Idę do lekarza.

12. Ablative
- Suffix: `-tól/-től`
- Meaning: from / away from / od
- Question: `skąd?`
- Example: `Levelet kaptam Katitól.` = I received a letter from Kati. / Dostałem list od Kati.

13. Instrumental-Comitative
- Suffix: `-val/-vel`
- Meaning: with / using
- Question: `z kim? z czym?`
- After a vowel, the suffix stays `-val / -vel`.
- After a consonant, the `v` assimilates to the final consonant, which is doubled.
- Formation: `autó + val → autóval`, `busz + val → busszal`
- Examples: `Autóval megyek.` = I go by car. / Jadę samochodem. `Busszal megyek.` = I go by bus. / Jadę autobusem.

14. Translative
- Suffix: `-vá/-vé`
- Meaning: into / become
- Question: `kim? czym się staje?`
- After a vowel, the suffix stays `-vá / -vé`.
- After a consonant, the `v` assimilates to the final consonant, which is doubled.
- Formation: `fiú + vá → fiúvá`, `tanár + vá → tanárrá`
- Examples: `Fiúvá válik.` = He becomes a boy. / Staje się chłopcem. `Tanárrá válik.` = He becomes a teacher. / Zostaje nauczycielem.

15. Essive-Formal
- Suffix: `-ként`
- Meaning: as / jako
- Question: `jako kto? jako co?`
- Example: `Tanárként dolgozik.` = He works as a teacher. / Pracuje jako nauczyciel.

16. Causal-Final
- Suffix: `-ért`
- Meaning: for / because of / dla, z powodu
- Question: `dla kogo? dla czego? z jakiego powodu?`
- Example: `A családomért dolgozom.` = I work for my family. / Pracuję dla mojej rodziny.

17. Terminative
- Suffix: `-ig`
- Meaning: until / as far as / do
- Question: `do kiedy? dokąd?`
- Example: `Hatig dolgozom.` = I work until six. / Pracuję do szóstej.

18. Temporal
- Suffix: `-kor`
- Meaning: at (time) / o (godzinie)
- Question: `kiedy?`
- Example: `Hatkor találkozunk.` = We meet at six o'clock. / Spotykamy się o szóstej.

#### Location questions & postpositions

- `Hol?` = Where? (location)
- `Hol vagy?` = Where are you?
- `Hova?` = Where to? (destination)
- `Hova mész?` = Where are you going?
- `Honnan?` = Where from? (origin)
- `Honnan jössz?` = Where are you coming from?

#### Location postpositions

Noun + postposition

- `a ház előtt` = in front of the house
- `a ház mögött` = behind the house
- `az asztal alatt` = under the table
- `az asztal fölött` = above the table
- `Péter mellett` = next to Péter
- `két ház között` = between two houses

Questions:

- `Hol?` → `előtt`, `mögött`, `alatt`, `fölött`, `mellett`, `között`
- `Hova?` → `elé`, `mögé`, `alá`, `fölé`, `mellé`, `közé`
- `Honnan?` → `elől`, `mögül`, `alól`, `fölül`, `mellől`, `közül`

#### Location pattern

Inside:
- `-ban/-ben` → in / w
- `-ba/-be` → into / do środka
- `-ból/-ből` → out of / ze środka

Surface:
- `-on/-en/-ön` → on / na
- `-ra/-re` → onto / na (ruch)
- `-ról/-ről` → off / from / z

At / near:
- `-nál/-nél` → at / u, przy
- `-hoz/-hez/-höz` → to / do
- `-tól/-től` → from / od

### Dative

# Celownik `-nak/-nek` = komu? / dla kogo?

Do rzeczowników:

- `Adok Katinak egy ajándékot.` = Daję Kati prezent.
- `Küldök neked egy üzenetet.` = Wysyłam ci wiadomość.

- `nekem` = mnie / dla mnie
- `neked` = tobie / dla ciebie
- `neki` = jemu, jej / dla niego, dla niej
- `nekünk` = nam
- `nektek` = wam
- `nekik` = im

## Adjectives

### Predicate Adjectives

When an adjective comes after the noun and is used with `to be`, it agrees with the subject.

- Singular: `A ház nagy.` = The house is big.
- Plural: `A házak nagyok.` = The houses are big.

Pattern:
- adjective + plural ending (`-k` with vowel harmony)

Question:
- `Milyen?` = What is ... like?
- `Milyenek?` = What are ... like?

#### Rule
- Before a noun → no plural
  - `piros alma`
  - `piros almák`
- After `to be` → adjective becomes plural
  - `Az alma piros.`
  - `Az almák pirosak.`

### Comparative

#### Core rule
Adjective + `-bb` (harmonized as `-abb / -ebb`).

#### Examples
- `nagy` → `nagyobb` (`big` → `bigger`)
- `kicsi` → `kisebb` (`small` → `smaller`)
- `gyors` → `gyorsabb` (`fast` → `faster`)
- `bátor` → `bátrabb` (`brave` → `braver`)
- `hosszú` → `hosszabb` (`long` → `longer`)

Usually formed by adding `-bb` with vowel harmony.

## Verbs

### Base Verbs

1. `van / nincs` → to be / exist / have
   - `vagyok, vagy, van / vagyunk, vagytok, vannak`
   - `van` disappears with profession/quality: `Ő tanár.`
   - it stays with location: `Ő itt van.`
2. `mieć` = `van` + possessive ending
   - `Van pénzem. / Nincs időm.`
   - literally: "there is my money/time"
3. `megy` → go
   - `megyek, mész, megy`
   - `Megyek dolgozni. / Hova mész?`
4. `jön` → come
   - `jövök, jössz, jön`
   - irregular stem: `jön → jöv-`
   - `Jövök! / Mikor jössz?`
5. `kap` → get / receive
   - `kapok, kapsz, kap`
   - `Kapok egy levelet.`
6. `csinál` → do / make
   - `csinálok, csinálsz, csinál`
   - `Mit csinálsz?`
7. `kell` → must / need to
   - the person is in the verb ending: `mennem kell, ennem kell, innom kell`
   - `kell` itself does not conjugate
8. `akar` → want
   - `akarok, akarsz, akar`
   - `akar + infinitive`
   - `Akarok enni.`
9. `kér` → ask / request
   - `kérek, kérsz, kér`
   - `kér + accusative`
   - `Kérek egy kávét. / Vizet kérek.`
10. `tud` → can / know / be able to
    - `tudok, tudsz, tud`
    - `tud + infinitive`
    - `Tudok magyarul. / Tudok úszni.`
    - negation: `nem tudok` = I do not know how / cannot

### Definite vs. Indefinite Conjugation

#### Choosing the conjugation
- Indefinite → general / non-specific object
  - `Olvasok egy könyvet.`
  - `Főzünk vacsorát.`
- Definite → specific object
  - `Olvasom a könyvet.`
  - `Ezt csináljuk.`
  - `Látom Pétert.`

Typical definite triggers:
- `a / az` (`the`)
- `ezt / azt` (`this / that`)
- possessives (`my, your...`)
- proper names (`Péter, Anna...`)

#### 2nd person singular (indefinite)
- `-sz` after most stems
- `-el/-ol/-öl` after stems ending in `s, sz, z, dz`

Examples:
- `vársz`
- `kérsz`
- `ülsz`
- `nézel`
- `főzöl`
- `olvasol`

#### Plural shortcuts (definite)

We:
- `-unk/-ünk` → `-juk/-jük`
- `csinálunk` → `csináljuk`
- `látunk` → `látjuk`

You (plural):
- `-tok/-tek/-tök` → `-játok / -itek`
- `csináltok` → `csináljátok`
- `kértek` → `kéritek`

They:
- `-ja` → `-ják`
- `-i` → `-ik`
- `várja` → `várják`
- `kéri` → `kérik`

#### Useful observation
3rd person singular often helps predict the plural definite forms:

- `várja` → `várjátok` → `várják`
- `kéri` → `kéritek` → `kérik`

The 1st person plural has its own pattern: `-juk/-jük`.

#### Remember
The hardest part is usually not the endings. First decide: "Is the object specific?" Only then choose indefinite or definite.

#### Additional notes
- `Hungarian Definite vs. Indefinite Conjugation`

`🔵 SINGULAR` / `🟣 PLURAL`

- `1st person singular (I, én)` / `1st person plural (we, mi)`
  - `várok, kérek, ülök` / `várunk, kérünk, ülünk`
  - `várom, kérem, ülöm` / `várjuk, kérjük, üljük`
- `2nd person singular (you, te)` / `2nd person plural (you-pl, ti)`
  - `vársz, kérsz, ülsz, nézel` / `vártok, kértek, ültök`
  - `várod, kéred, ülöd` / `várjátok, kéritek, ültitek`
- `3rd person singular (he/she/it, ő)` / `3rd person plural (they, ők)`
  - `vár, kér, ül` / `várnak, kérnek, ülnek`
  - `várja, kéri, üli` / `várják, kérik, ülik`

### Verbal Prefixes

#### Core rule
Verbal prefixes modify the meaning of a verb. They often express completion, result, direction or a change of state.

#### Examples
- `ír` → `megír` = write → write completely / finish writing
- `tanul` → `megtanul` = study → learn
- `főz` → `megfőz` = cook → cook completely
- `lát` → `meglát` = see → notice
- `un` → `megun` = get bored / get tired of

#### Common prefixes
- `meg-` → completion / result
- `el-` → away, leave, disappear
- `fel-` → up
- `le-` → down
- `ki-` → out
- `be-` → in
- `vissza-` → back
- `át-` → across
- `rá-` → onto
- `össze-` → together

#### Prefix position

Neutral:
- prefix + verb
- `meglátom`
- `elengedlek`
- `meguntam`

Negation / question word / focus:
- verb + prefix
- `nem látom meg`
- `mit írtál meg?`
- `kit engedsz el?`
- `csak hívom fel`

Yes/No question:
- prefix + verb
- `Megírtad?`
- `Meguntad a repülést?`

#### Rule
The verbal prefix normally comes before the verb. After negation (`nem`), a question word (`mit, kit, hova...`) or a focused element, it moves after the verb.

#### Note
- `meg-` often marks completion or a resulting state.

### Expressing Emotions

- `én → te/ti` → `-lak / -lek` (optionally add `titeket`)
- `én → ő/ők` → definite (`-om/-em`)

Examples:
- `Szeretlek` = I love you
- `Látlak` = I see you
- `Várlak` = I am waiting for you
- `Ismerlek` = I know you
- `Hallak` = I hear you
- `A nagymamám nem hall minket` = my grandma doesn’t hear us
- `Nézlek` = I am looking at you
- `Utállak` = I hate you
- `Imádlak` = I adore you
- `Imád engem` = he adores me
- `Imádnak engem` = they adore me
- `Hallgatlak` = I am listening to you

### Generic Singular

Hungarian often uses the singular form to express things in general where English uses the plural.

- `Ajándékot hozunk.` = We bring presents.
- `Könyvet olvasok.` = I read books.
- `Almát eszünk.` = We eat apples.

Use the plural when referring to specific, identifiable items:

- `Az ajándékokat hozzuk.` = We are bringing the presents.

## Word Formation

### `-ít`
`-ít` = make / cause to become (`tworzy czasownik z rzeczownika lub przymiotnika`)

- `tovább` → `továbbít` = przekazywać dalej
- `tiszta` → `tisztít` = czyścić (`uczynić czystym`)
- `gyors` → `gyorsít` = przyspieszać (`uczynić szybszym`)
- `lassú` → `lassít` = zwalniać (`uczynić wolniejszym`)

### `-ás / -és`
`-ás / -és` = action / process (`tworzy rzeczownik odczasownikowy`)

- `tanul` → `tanulás` = nauka / uczenie się
- `ír` → `írás` = pisanie
- `olvas` → `olvasás` = czytanie
- `beszél` → `beszélés` = mówienie / rozmowa

### `-ó / -ő`
`-ó / -ő` = person or thing performing the action (`tworzy wykonawcę czynności lub coś wykonującego czynność`)

- `tanul` → `tanuló` = uczeń
- `olvas` → `olvasó` = czytelnik
- `hallgat` → `hallgató` = słuchacz / student
- `forog` → `forgó` = obracający się / obrotowy

### `-s`
`-s` = person or thing associated with something (`często tworzy nazwę osoby lub cechy związanej z rzeczownikiem`)

- `munka` → `munkás` = pracownik
- `zene` → `zenés` = muzyczny
- `cukor` → `cukros` = słodki / zawierający cukier
- `folt` → `foltos` = poplamiony / w plamy

## Vowel Harmony

### Vowel groups
1. Front vowels: `e, é, i, í, ö, ő, ü, ű`
2. Back vowels: `a, á, o, ó, u, ú`

### Vowel harmony rules
1. Back vowel words: if the root word contains back vowels, suffixes added to the word also contain back vowels.
   - `Ház, házak, házban`
   - `Bolt, boltok, boltban`
2. Front vowel words: if the root word contains front vowels, suffixes added to the word contain front vowels.
   - `Kert, kertek, kertben`
   - `Szék, székek`
3. Mixed vowel words: if the root word contains both front and back vowels, the suffixes usually follow the last vowel in the root word.

## Cluster Breaks

Hungarian inserts `a/e/o/ö` to avoid impossible consonant clusters.

- `hall + sz → hallasz` (`LLSZ` impossible)
- `segít + ni → segíteni` (`TNI` impossible)
- `tölt + sz → töltesz` (`LTSZ` impossible)
- `mond + sz → mondasz` (`DSZ` impossible)
- `isz + sz → iszol` (`SZSZ` impossible)
- `esz + sz → eszel` (`SSZ` impossible)
- `tesz + sz → teszel` (`S + SZ` impossible)
- `haggy + sz → hagysz` (`GGSZ` impossible)
- `tört + sz → törtesz` (`RTSZ` impossible)

## Miscellaneous Tips

### Core intuition
Hungarian usually avoids marking plurality twice. If plurality is already clear from a number, a quantity word, or a generic meaning, the noun usually remains singular.

### Quick summary
Use singular when:
- after numbers
- after quantity words
- when talking about a species or class in general

Use plural when:
- when referring to a specific group
- when nothing else already indicates plurality

### Common mistakes
- `két kutyák` → `két kutya`
- `sok könyvek` → `sok könyv`
- `három barátaim` → `három barátom`
- `A tigrisek veszélyes.` when talking about the species → `A tigris veszélyes.`

### Remember
The hardest part is usually not the endings. First decide: "Is the object specific?" Only then choose indefinite or definite.
